Pesquisa de Satisfação - TudoWeb

Este projeto consiste em um script em Python desenvolvido para automatizar a coleta de opiniões sobre o atendimento da empresa de marketing TudoWeb.

O programa utiliza estruturas de repetição, controle de fluxo moderno com match/case e contadores para compilar os resultados da pesquisa.

🛠️ Funcionalidades

Coleta de Dados: Solicita nome, idade e a opinião do entrevistado sobre o serviço prestado.

Opções de Avaliação:

1: EXCELENTE

2: BOM

3: RUIM

Estrutura de Repetição: Executa a pesquisa para uma quantidade configurável de clientes (por padrão, 10 para testes e 50 para a versão final).

Relatório Final: Exibe ao fim das entrevistas a contagem total das respostas de cada categoria.
