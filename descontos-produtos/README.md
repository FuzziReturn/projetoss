# Sistema de Desconto em Compras

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python como parte de uma atividade do curso.

O programa solicita ao usuário o valor total de uma compra e calcula automaticamente o desconto de acordo com o valor informado.

## 💰 Regras de desconto

- Compras menores que **R$ 200,00** recebem **5% de desconto**.
- Compras de **R$ 200,00 até menos de R$ 300,00** recebem **10% de desconto**.
- Compras de **R$ 300,00 ou mais** recebem **15% de desconto**.

## 🐍 Tecnologias utilizadas

- Python 3

## ⚙️ Como funciona

Primeiro, o programa pede o valor total da compra.

Depois, utilizando estruturas condicionais `if`, `elif` e `else`, ele verifica qual porcentagem de desconto deve ser aplicada.

Por fim, o programa mostra:

- Valor da compra;
- Percentual de desconto;
- Valor do desconto;
- Valor final a pagar.
